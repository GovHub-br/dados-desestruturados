Uma camada de interpretação para documentos complexos

O projeto Dados Desestruturados parte de um problema concreto: muitos documentos relevantes existem em PDF, mas o conteúdo útil dentro deles não está organizado para análise, automação ou revisão incremental. Títulos, números, tabelas, gráficos e narrativa convivem no mesmo arquivo, mas sem uma estrutura imediatamente reaproveitável.

A pipeline foi desenhada para reconstruir esse contexto. Em vez de extrair apenas texto corrido, ela tenta mapear onde cada item aparece, a que seção pertence, em que ordem foi lido e quais relações estruturais o documento convertido preserva. Isso cria uma base muito mais forte para inspeção, correção e evolução futura.

Problema

Dados importantes ficam presos em formatos visuais, com contexto disperso e baixa reutilização computacional.

Abordagem

O projeto usa o Docling como base estrutural e complementa a leitura com heurísticas de títulos, contexto, números e extração semântica opcional.

Resultado

O documento passa a existir como uma coleção rastreável de seções, blocos, métricas, tabelas, gráficos e fatos narrativos.
